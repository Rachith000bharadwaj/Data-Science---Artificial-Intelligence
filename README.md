# Artificial Intelligence Project

This repository contains the lightweight upload of the 3rd semester Artificial Intelligence project.

## Project Contents

- `KSRTC_Project_Submission/1.Jupyter Notebooks/` - data collection, preparation, AI model development, and Flask API notebooks.
- `KSRTC_Project_Submission/2.Backend/` - backend notebooks, route data, and requirements.
- `KSRTC_Project_Submission/3.Frontend/` - admin and commuter frontend applications.
- `Overview.pdf` - project overview document.
- `Report.pdf` - final project report.
- `PPT.pptx` - project presentation.
- `Part Distribution.docx` - team work distribution document.

## Not Uploaded

The following local items were intentionally excluded because they are too large or not suitable for GitHub:

- `DATASETS/`
- `Video.mp4`
- `.venv/`

## Notes

The repository is kept lightweight so it can be cloned and viewed easily on GitHub without large dataset or environment files.
